แถบเมนูการจัดการ (Menu)

➕ เพิ่มรายการตารางสอนใหม่

รองรับทั้งตารางเรียนประจำสัปดาห์ และตารางเรียนระบุวันที่เฉพาะเจาะจง (เช่น คลาสชดเชย)

📋 รายการตารางสอนทั้งหมด (0 รายการ)

วัน / วันที่เฉพาะ เวลา รายวิชา ครูผู้สอน นักเรียน ห้องเรียน สถานะ จัดการ

👨‍🏫 จัดการรายชื่อครูผู้สอน (Teachers)

รายชื่อครูที่บันทึกไว้จะแสดงเป็นตัวเลือกอัตโนมัติเวลาเพิ่มตารางสอน

🚪 จัดการห้องเรียนสตูดิโอ (Studio Rooms)

เพิ่มหรือลบห้องซ้อมและห้องเรียนสำหรับแสดงผลแยกคอลัมน์บนหน้าจอหลัก

🎵 จัดการรายวิชาดนตรีและการแสดง (Subjects)

เพิ่มรายวิชาที่เปิดสอนในสถาบัน BRF KORAT STUDIO

📥 ส่งออกและนำเข้าข้อมูล (Export / Import Excel CSV & JSON)

ดาวน์โหลดตารางสอนเก็บไว้เป็นไฟล์ Excel (CSV) หรือไฟล์ฐานข้อมูล JSON เต็มรูปแบบ และสามารถอัปโหลดกลับเข้าสู่ระบบได้ตลอดเวลา

📊 ส่งออกข้อมูล (Export)

ไฟล์ CSV รองรับภาษาไทย (UTF-8 BOM) เปิดด้วยโปรแกรม Microsoft Excel หรือ Google Sheets ได้ทันที

📤 นำเข้าข้อมูล (Import)

เลือกไฟล์ `.json` หรือ `.csv` เพื่อนำเข้าตารางสอนขึ้นไปยัง Cloudflare KV

📢 ตั้งค่าชื่อสถาบัน ข้อความวิ่ง และรหัสผ่านผู้ดูแลระบบ (Admin PIN)

บันทึกข้อมูลและอัปเดตหน้าจอเรียบร้อยแล้ว!
